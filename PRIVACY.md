# Privacy Policy — Vim Keys

Vim Keys is a Safari web extension (and a Firefox add-on). It does not collect,
transmit, sell or share any personal data.

- **No network access.** The extension makes no network requests and contains no
  analytics, telemetry or advertising code.
- **Local storage only.** Settings, key bindings and the 36 quick-site slots are
  stored in the browser's own extension storage on your Mac. They never leave
  the machine.
- **Page access.** The extension reads the pages you visit only to draw hint
  labels, scroll, find text and show the URL panel. Nothing about those pages is
  stored or sent anywhere.
- **No accounts, no tracking, no third parties.**

Uninstalling Vim Keys removes its local data. Questions: open an issue at
https://github.com/lylehust/Vim-Keys/issues.
